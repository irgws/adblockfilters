# AdBlock DNS Filters

去广告合并规则，每8个小时更新一次。

本项目为 [217heidai/adblockfilters](https://github.com/217heidai/adblockfilters) 的镜像仓库，由 GitHub Actions 每 8 小时自动同步上游规则，提供多 CDN 加速订阅。

## 说明

1. 定时从上游 [217heidai/adblockfilters](https://github.com/217heidai/adblockfilters) 的 GitHub Release 同步规则，每 8 小时一次。
2. 本项目仅做同步分发，不做任何规则修改。如发现误拦截情况，可临时添加放行规则（如 `@@||www.example.com^$important`），并向上游规则反馈。
3. 各 CDN 缓存刷新延时不同，如刚更新后仍取到旧版本，可切换其他加速链接或稍后重试。

## 订阅链接

1. 规则x' 为规则x的 Lite 版，仅针对国内域名拦截，体积较小（如添加完整规则报错数量限制，请尝试 Lite 规则）
2. AdGuard Home 等 DNS 拦截服务使用规则1
3. AdGuard 等浏览器插件使用规则1 + 规则2（规则2为规则1的补充，仅适用浏览器插件）
4. InviZible Pro、personalDNSfilter 使用规则3（规则3与规则1拦截域名一致，仅格式差异）
5. DNSMasq 使用规则4（与规则1拦截域名一致，仅格式差异）
6. SmartDNS 使用规则5（与规则1拦截域名一致，仅格式差异）
7. Shadowrocket 使用规则6（与规则1拦截域名一致，仅格式差异）
8. Shadowrocket Module 使用规则7

10. Clash Meta(Mihomo) 使用规则9 yaml 或 规则10 mrs（与规则1拦截域名一致，仅格式差异）
11. Hosts 使用规则11（与规则1拦截域名一致，仅格式差异）

## 更新机制

- 由 GitHub Actions 定时任务驱动，每 8 小时自动从上游 Release 同步
- 仅在有变更时产生 commit，避免空提交
- 各 CDN 缓存刷新延时不同（通常几分钟到半小时），如刚更新后仍取到旧版本，可切换其他加速链接或稍后重试
